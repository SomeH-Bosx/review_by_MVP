题1：计算每个部门的累计销售额占比

要求：输出每行的销售额、部门累计销售额、部门总销售额、累计占比（保留2位小数）

参考答案：

SELECT
    dept_id,
    sale_date,
    amount,
    SUM(amount) OVER(PARTITION BY dept_id ORDER BY sale_date) AS cum_amount,
    SUM(amount) OVER(PARTITION BY dept_id) AS dept_total,
    ROUND(
        SUM(amount) OVER(PARTITION BY dept_id ORDER BY sale_date) * 100.0 
        / SUM(amount) OVER(PARTITION BY dept_id),
        2
    ) AS cum_ratio
FROM sales;

输出结果（部门1）：

dept_id sale_date amount cum_amount dept_total cum_ratio
1 2024-01-01 100 100 2100 4.76
1 2024-01-02 200 300 2100 14.29
1 2024-01-03 300 1000 2100 47.62
1 2024-01-03 400 1000 2100 47.62
1 2024-02-01 500 1500 2100 71.43
1 2024-02-02 600 2100 2100 100.00

解析：

  • 两个窗口函数同时使用：一个带 ORDER BY（累计求和），一个不带（部门总销售额）
  • 注意乘以 100.0 而不是 100，避免整数除法导致结果为0
  • 两个1月3日的行累计值相同，因为 RANGE 默认会把相同排序值的行合并计算
题2：计算每个部门的"近2日销售额总和"

要求：计算"当天 + 前1天"的销售额总和，注意边界情况

参考答案：

SELECT
    *,
    SUM(amount) OVER(
        PARTITION BY dept_id
        ORDER BY sale_date
        ROWS BETWEEN 1 PRECEDING AND CURRENT ROW
    ) AS last_2d_sum
FROM sales;

输出结果：

dept_id sale_date amount last_2d_sum
1 2024-01-01 100 100
1 2024-01-02 200 300
1 2024-01-03 300 500
1 2024-01-03 400 700
1 2024-02-01 500 900
1 2024-02-02 600 1100
2 2024-01-01 150 150
2 2024-01-02 250 400
2 2024-01-03 350 600
2 2024-02-01 400 750
2 2024-02-02 500 900

解析：

  • 必须使用 ROWS 而不是 RANGE，否则相同日期的行会被合并计算
  • 第一行没有前一行，所以只计算自己
  • 部门1的两个1月3日：
    • 第一个300：加前一行200 → 500
    • 第二个400：加前一行300 → 700
题3：找出错误并修正

问题：以下SQL想计算"每个部门每日销售额总和"，但结果不对，请找出错误并修正

SELECT
    dept_id,
    sale_date,
    SUM(amount) OVER(PARTITION BY dept_id ORDER BY sale_date) AS daily_sum
FROM sales;

错误原因：

加了 ORDER BY 后，窗口默认是 RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW，变成了累计求和，而不是每日求和。

正确写法：

SELECT
    dept_id,
    sale_date,
    SUM(amount) OVER(PARTITION BY dept_id, sale_date) AS daily_sum
FROM sales;

输出结果：

dept_id sale_date daily_sum
1 2024-01-01 100
1 2024-01-02 200
1 2024-01-03 700
1 2024-01-03 700
1 2024-02-01 500
1 2024-02-02 600
2 2024-01-01 150
2 2024-01-02 250
2 2024-01-03 350
2 2024-02-01 400
2 2024-02-02 500

关键提醒：

  • 窗口函数中，PARTITION BY 是"分组"，ORDER BY 是"组内排序并累计"
  • 想计算"分组内的静态聚合"，不要加 ORDER BY
挑战题：计算每个部门的月度环比增长率

要求：计算每个部门每月销售额相对于上月的环比增长率，保留2位小数

公式：环比增长率 = (本月销售额 - 上月销售额) / 上月销售额 × 100%

参考答案：

-- 第一步：先计算每个部门每个月的总销售额
WITH monthly_sales AS (
    SELECT
        dept_id,
        DATE_FORMAT(sale_date, '%Y-%m') AS month,
        SUM(amount) AS monthly_amount
    FROM sales
    GROUP BY dept_id, month
)
-- 第二步：用LAG()获取上月销售额，计算环比增长率
SELECT
    dept_id,
    month,
    monthly_amount,
    LAG(monthly_amount) OVER(PARTITION BY dept_id ORDER BY month) AS last_month_amount,
    ROUND(
        (monthly_amount - LAG(monthly_amount) OVER(PARTITION BY dept_id ORDER BY month)) * 100.0
        / LAG(monthly_amount) OVER(PARTITION BY dept_id ORDER BY month),
        2
    ) AS growth_rate
FROM monthly_sales;

输出结果：

dept_id month monthly_amount last_month_amount growth_rate
1 2024-01 1000 NULL NULL
1 2024-02 1100 1000 10.00
2 2024-01 750 NULL NULL
2 2024-02 900 750 20.00

解析：

  • 使用CTE（公共表表达式）分两步计算，逻辑更清晰
    • 第一步：先聚合每日数据，得到每个部门每个月的总销售额
    • 第二步：在月度数据上使用窗口函数计算环比
  • LAG(monthly_amount) OVER(PARTITION BY dept_id ORDER BY month)
    • PARTITION BY dept_id：每个部门单独计算
    • ORDER BY month：按月份排序，这样LAG()才能取到上一个月的数据
  • 第一个月没有上月数据，所以last_month_amount和growth_rate都是NULL
  • 如果需要把NULL显示为0，可以用COALESCE(growth_rate, 0)函数

拓展：

如果需要计算同比增长率（和去年同月相比），只需要把LAG()的第二个参数改为12：

LAG(monthly_amount, 12) OVER(PARTITION BY dept_id ORDER BY month)

第二部分：推断统计练习题

题4：置信区间计算

题目：某电商想估计用户的平均月消费金额，随机抽取了64名用户，得到：

  • 样本均值：200元
  • 样本标准差：40元

计算：

  1. 95%置信区间
  2. 99%置信区间
  3. 如果样本量增加到256，95%置信区间会变成多少？

（常用z值：95%→1.96，99%→2.58）

公式：

置信区间 = x̄ ± zα/2 × (s / √n)

计算过程：

  1. 95%置信区间（n=64）：

    标准误 SE = 40 / √64 = 5

    置信区间 = 200 ± 1.96 × 5 = [190.2, 209.8]

  2. 99%置信区间（n=64）：

    置信区间 = 200 ± 2.58 × 5 = [187.1, 212.9]

  3. 95%置信区间（n=256）：

    标准误 SE = 40 / √256 = 2.5

    置信区间 = 200 ± 1.96 × 2.5 = [195.1, 204.9]

结论：

  • 置信水平越高，区间越宽（越容易包含真实值，但精度越低）
  • 样本量越大，区间越窄（精度越高）
题5：概念判断题（必做！90%的人会错）

题目：判断以下关于95%置信区间的说法是否正确，并解释原因

  1. "真实的总体均值有95%的概率落在这个区间里"
  2. "有95%的样本均值会落在这个区间里"
  3. "如果重复抽样100次，计算100个置信区间，大约有95个会包含真实的总体均值"
  4. "这个区间有95%的概率包含真实的总体均值"

答案与解析：

  1. ❌ 错误

    真实的总体均值是一个固定不变的常数，不是随机变量。它要么在区间里，要么不在，不存在"概率"一说。

  2. ❌ 错误

    置信区间是围绕本次样本均值构造的，不是用来包含其他样本均值的。

  3. ✅ 正确

    这是置信区间的唯一正确定义。概率是针对"构造区间的方法"而言的，不是针对某个具体的区间。

  4. ❌ 错误

    和第1题同理，具体的某个区间是固定的，它要么包含真实值，要么不包含。我们只能说"用这个方法构造的区间，有95%的概率能包含真实值"。

通俗总结：

置信区间说的是"方法的成功率"，不是"某个区间的成功率"。
